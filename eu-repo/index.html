源显示"无效/无法使用"？三步排障（常见于换包后缓存）

本源包会持续更新（如 0.9.1-2 → 0.9.1-3）。Sileo 若缓存了旧索引，会去拉已下架的旧文件名导致 404、源显示无效。解法：
① Sileo「源」页左上角 → 选中本源 → 删除；
② 重新添加：https://euphoria-repo.surge.sh/（原样复制，含结尾斜杠）；
③ 若仍无效：Sileo 设置 → 清除缓存（Clear Cache / 刷新所有源），再回到第②步。
