# Euphoria UI 设计规范（05 号）

> 版本：v1.1 ｜ 制定：报告汇总员 ｜ 2026-08-26 17:35 发布，17:46 回填 §4 实现路径（ADR-013 定案）｜ 依据：用户 17:27 指令（R13）"UI要精美…开机动画要美观，图标也要精美，前面的开机动画，也就是图标，应用内颜色固定，和图标颜色一样，你们也可以自己决定"
> 本规范是前端实现与视觉资产的**强制标准**，B 实现时逐项对照；验收时汇总员按 §六逐项核对。

## 一、品牌定位与视觉概念

- **产品名**：Euphoria（极乐）
- **概念关键词**：欣快 / 光晕 / 升维——"越狱成功的瞬间 = 欣快感"
- **视觉隐喻**：深空中绽放的光核（euphoric core）——图标即光核，开机动画即光核苏醒，应用内一切主色源自光核
- **差异化**：Dopamine 蓝白冷调 → Euphoria 用**紫→品红热渐变**，一眼可辨

## 二、色彩系统（应用内颜色=图标颜色，全局固定）

### 2.1 核心色板（Hex，全局常量，禁止临时色值）

| 令牌 | 色值 | 用途 |
|---|---|---|
| `EUCore`（主色） | `#8B5CF6` | 图标光核主色；导航栏/按钮/开关开启态/进度环 |
| `EUGlow`（辉光色） | `#D946EF` | 图标光晕外缘；渐变终点；强调高亮 |
| `EUDeep`（底色） | `#0D0B14` | 深色背景基色（近黑紫） |
| `EUSurface` | `#171325` | 卡片/设置组背景 |
| `EUTextPrimary` | `#F4F1FA` | 主文本 |
| `EUTextSecondary` | `#A79FC0` | 次级文本/说明 |
| `EUSuccess` | `#34D399` | 越狱成功态 |
| `EUWarning` | `#FBBF24` | 警告（如 rootful 耗时提示） |
| `EUDanger` | `#F87171` | 错误/危险操作 |
| `EUInterpose`（roothide 态） | `#38BDF8` | "隐藏已生效"徽标（冷色对比，示意隐匿） |

### 2.2 渐变公式（全局唯一，图标/按钮/进度共用）

- `EUGradient = linear 135°, #8B5CF6 → #D946EF`
- 开机动画辉光单独叠加径向渐变：`radial, #D946EF@48% → transparent@100%`

### 2.3 明暗模式

- **默认深色**（越狱工具场景惯例）；浅色模式仅做背景/文本反转，核心色令牌不变（保证"颜色固定"指令）

## 三、应用图标规范（图标精美 + 即开机动画主体）

- 画布：1024×1024，iOS 圆角由系统裁切（不自绘圆角）
- 构成：
  1. 背景：`EUDeep` → 底部微透 `#1A1230` 的垂直渐变
  2. 主体：中央光核——抽象 "E" 字形由三道弧光构成，材质感=磨砂玻璃+内辉光，填充 `EUGradient`
  3. 光晕：光核外 `EUGlow` 径向辉光（透明度 40%→0）
  4. 细节：光核右上 1px 高光弧（#FFFFFF@30%）
- 禁止：照片素材/第三方图标/文字（产品名以外）/小于 8px 的细节
- 交付物：`AppIcon.appiconset` 全尺寸 + 源文件（SVG/PNG）

## 四、开机动画规范（越狱完成时播放）

- **主体**：应用图标的光核（与图标 1:1 同源），全屏 `EUDeep` 底
- 时长：2.4s，三阶段（easing 全局用 cubic-bezier(0.22, 1, 0.36, 1)）：
  1. **0~0.8s 苏醒**：光核从 0.6 缩放+20% 透明度淡入至全亮，辉光同步扩散
  2. **0.8~1.8s 脉动**：光核呼吸缩放 1.0↔1.06（2 周期），进度环（2px，`EUGradient`）绕光核顺时针扫过并显示阶段文案（如"正在注入欣快…"）
  3. **1.8~2.4s 绽放**：辉光一次全屏扩散（`EUGlow`@24%→0）后淡出进入主界面
- 结束行为：动画可被跳过（点击即跳，不卡流程）；动画期间禁止主线程阻塞（动画编码于启动路径之外）
- **实现路径**（v1.1 回填，ADR-013 定案；源：A 专项报告 17:45 + C6 交叉验证）：
  1. **主路径 A｜应用内越狱动画**：SwiftUI 原生实现（TimelineView + Canvas + keyframe），**不引 Lottie 等第三方库**（自研边界）；点击越狱按钮即播放、与越狱管线并行，直接承载本节三阶段时间轴
  2. **增强路径 B｜respring 过渡叠加**：越狱管线末端 respring/ldrestart 瞬间，由注入层在 SpringBoard 窗口层级叠加全屏品牌动画至 SB 就绪；按"动效优先、静帧兜底"双档实现；**可感知启动延迟 >300ms 即砍**
  3. **不采用**：launchd 级注入（与 B 路径观感重叠，留 V2 评估）；冷开机 boot logo 判**硬不可行**——Apple logo 由 iBoot 从 NOR 读取绘制，替换必经 bootchain 漏洞（24kpwn/checkm8/usbliter8，均属被规则排除的硬件路径），semi-untethered 工具史无一例外；终审报告向用户明示此预期
  4. **双流程视觉区分（R11）**：rootful 开启时脉动阶段追加"能量注入"辉光渐变层次（限 §2.1 色板令牌内），roothide 默认态保持标准三阶段；脉动阶段编排与 A12/A13 exploit 熄屏窗口对齐（A×C 衔接点，见 ADR-013）
  - 无论何种路径，视觉规格以本节为准
- 静态降级：若技术路径仅支持静帧，则交付"光核绽放帧"作为 boot logo（与图标同源）

## 五、界面组件规范（R11/R12 落点）

### 5.1 设置页新增行（R11：rootful 开关）

- 分组："越狱形态"；行高 52pt，`EUSurface` 卡片，12pt 圆角
- 左：标题"Rootful 模式"+ 副文案（`EUTextSecondary`，13pt）："开启后以 fakefs 实现真根可写，叠加完整隐藏栈；越狱耗时显著增加"
- 右：iOS 原生风格 toggle，开启态填充 `EUGradient`（关=灰 `#3A3547`）
- **范围外机型**（非 A12/A13 或系统 <16.6.1 或 >18.7.1）：toggle 置灰禁用，右侧信息图标点击弹出说明面板（`EUWarning` 主色）："Rootful 仅支持 A12~A13 · iOS 16.6.1~18.7.1"
- 默认值：**关**；切换时若已越狱，提示"下次越狱生效，是否立即重新越狱？"

### 5.2 越狱流程分支提示（ADR-011）

- roothide 分支进度文案与 rootful 分支区分；rootful 分支在**建卷+复制阶段**（ADR-014 mount-over 口径，首次开启分钟级）显示 `EUWarning` 色提示"正在生成根可写副本（约需数分钟）"并配进度反馈；文案区分首次"激活"与历次"恢复"（秒级 remount，无需进度页）

### 5.3 致谢页（R12）

- 入口：设置 → 关于 → 致谢
- 结构：①**特别致谢：mg13-14**（首行，`EUTextPrimary`，17pt 半粗）②项目团队 ③开源组件与许可（MIT/BSD 各条目，`EUTextSecondary`，13pt）
- 页面顶部放光核 logo（同图标主体，48pt）

### 5.4 通用

- 字体：系统 SF Pro（Dynamic Type 适配）；标题 17pt 半粗 / 正文 15pt / 说明 13pt
- 间距系统：8/12/16/24pt 网格；卡片圆角统一 12pt
- 深色底上的交互反馈：按压态 `EUSurface` 变亮 +8%
- 所有 alert/sheet 背景统一 `EUSurface`，主按钮统一 `EUGradient`

## 六、验收清单（汇总员终审用）

1. 图标与开机动画主体**同源**（同一光核资产导出）
2. 应用内出现的所有主色/渐变仅来自 §2.1 令牌（代码内禁止散落色值，统一走 `EUTheme` 常量）
3. R11 开关行为：默认关；置灰条件正确；分支流程文案区分
4. R12 致谢页含 mg13-14 且排版为首行
5. 开机动画三阶段时间轴与 easing 符合 §四；可跳过；不阻塞
6. 深浅两模式下核心色不变
7. 视觉资产全部自研产出（合 ADR-008 自研边界，禁用第三方图标素材库成品）
