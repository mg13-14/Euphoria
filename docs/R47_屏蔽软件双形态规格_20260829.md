## 一、模式检测→形态映射（核心机制=自动，无新开关）

屏蔽系统（cloakd/aegisd）启动与越狱会话建立时，读两个 jbsettings 键（与 App 设置页同源，单一真值源）：

| rootfulUserEnabled | roothideUserEnabled | 模式 | 屏蔽形态 | 目标方向（用户语义） |
|---|---|---|---|---|
| 1 | 1 | rootful（捆绑联动，R43 保证） | **Form-B 宽向量形态** | 应用**不能知道我们能动系统**（屏蔽向量更宽：连"系统能力异常"都测不出） |
| 0 | 1 | roothide | **Form-A 窄向量形态** | 应用**不能知道我们越狱了**（实现同样内核级，仅屏蔽向量集较窄——ADR-017 无浅层选项） |
| 0 | 0 | rootless（默认） | 无系统级屏蔽（仅 App 隐/显越狱，Dopamine 同款） | — |
| 1 | 0 | ——（R43 联动约束禁止：关 roothide 强制关 rootful） | — | — |

形态切换时机：越狱启动链（euphoria main.m 模式分支处）一次性判定+套用形态预设；越狱中开关 rootful 的 enable/disable 事件同步推 cloakd 热切换（jbctl rootful enable/disable 现有调用点顺带 cloak set）。

## 二、两形态策略矩阵

### Form-A 窄向量形态（roothide 态=防"越狱检测"；实现深度同为内核级——ADR-017 禁"浅层"）

现有 cloak_policy_t 三 hide 面全开+基础 stealth：

| 策略面 | 状态 | 说明 |
|---|---|---|
| hideMounts | ✓ 现有 | getfsstat/statfs 过滤 /var/jb 系挂载（应用查挂载表→无异常） |
| hideCredentials | ✓ 现有 | kinfo_proc/ucred 提权进程伪装（查 uid 0 进程列表→无异常） |
| hideTrustcache | ✓ 现有 | csops 遮蔽 CS_DEBUGGED 等注入痕迹（越狱 app 签名态→正常） |
| stealthLevel | 0（paranoid 基础档） | 现有 |
| aegis per-app | ✓ 现有 | 按应用隐藏（jailbreak app 图标/名单） |

### Form-B（rootful 态=防"系统能力异常检测"，新增策略面）

Basic 全部继承，**追加 rootful 特有暴露面**（rootfs 可写带来的新检测向量——这正是"更深"的实体）：

| 策略面 | 状态 | 说明（应用侧检测向量→屏蔽后呈现） |
|---|---|---|
| **hideRootfsWrites** | ★新增字段 | rootful 会话期 /System、/usr 的写入痕迹（新文件/mtime/大小差异）→呈现与密封卷一致 |
| **hideRemountFlags** | ★新增字段 | mount 系统调用返回的 root 卷 MNT_RDONLY 位→呈现只读（实际已 remount RW） |
| **hideSSVState** | ★新增字段 | SSV/seal 相关状态查询（CS 严格模式、csrctl 类）→呈现出厂态 |
| stealthLevel | 0（deep 档全 paranoid） | 沿用，语义=过滤器从严 |
| aegis per-app | ✓ 继承 | 不变 |

技术依据：hideRootfsWrites/hideRemountFlags 的过滤点=launchdhook 已有的系统调用拦截层（mount/getfsstat/statfs 已拦，加"对 root 卷返回伪造 flags"分支）；hideSSVState 走 csops/AMFI 呈现层（hideTrustcache 同族）。**全部是现有拦截架构的扩展项，非新架构**。

## 三、数据结构与命令面变更（B 落码清单）

1. cloak_policy_t 追加 3 个 bool：`hideRootfsWrites`/`hideRemountFlags`/`hideSSVState`（cloak.h+cloak.c 序列化对+launchdhook 真值源）。
2. 形态预设：`cloak_apply_form_preset(bool deep)`——Form-B=6 面全开；Form-A=3 面+deep 三项 false。越狱启动链按 §一 映射调用。
3. jbctl cloak set 扩展三个 key（现有 set hideMounts=1 模式顺延，测试用）。
4. App UI **不加开关**（用户语义=自动检测自动切换；高级用户可 jbctl 微调，非 UI 面）。
5. 联动热切换：jbctl rootful enable/disable 成功回调处顺带 `cloak_apply_form_preset(enable)`（越狱中开 rootful→即时升深层）。

## 四、验收口径（对应"两种形态"的可测差异（形态差别=屏蔽向量覆盖面，实现深度同为内核级））

1. Form-Basic：检测类 app（如越狱检测器）查挂载/进程/签名→无异常；但 rootfs 若有写入痕迹仍可见（不掩盖——roothide 态本来无 rootfs 写）。
2. Form-Deep：Basic 三项通过+root 卷 mount flags 呈现只读+rootfs 写入痕迹不可见（深层向量全闭合）。
3. 形态自动性：改模式重越狱后无需手动操作，cloakd 套对形态（启动日志打印 form=wide/narrow）。
