## 五、红线清单（持续约束后续所有改动）

| 红线项 | 位置 | 原因 |
|---|---|---|
| exploit Info.plist 的 `DPExploitType` / `DPExploitFlavors` / `DPFlavorPriority` / `DPSupportedDevices` / `DPSupportedRanges` 键名 | 全部 `Exploits/*/Info.plist` | `EUExploitManager` 运行时加载契约（已被 A 的闸门模块依赖，叠加后仍为 DP 前缀，**属刻意保留**） |
