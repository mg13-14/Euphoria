## 一、设计语言总纲："仙境"

四个关键词：**深空 / 流光 / 毛玻璃 / 微粒**。

- 整体氛围 = 夜幕仙境：深色沉浸底 + 极光色点缀，界面元素如浮空宫阙。
- 交互隐喻 = "登仙之途"：一步一境界，状态即修行（文案映射见 §九）。
- 克制律：动效层永远 ≤2（粒子层+光晕层二选一叠加），60fps 优先，ProMotion 适配。

## 二、色彩体系（dark 基调）

| 层 | 色值 | 用途 |
|---|---|---|
| 底·深空 | `#0B0E2A → #1B1443 → #2E1B5E`（三段纵向渐变，CAGradientLayer） | 全屏背景 |
| 强调·极光 | `#7CF3D0 → #5E8BFF → #B47CFF`（横向三段） | 主按钮/进度条/选中态 |
| 状态·成功 | 荧光青绿 `#5CE8B5`（含 0.4 透明度呼吸光晕） | ✅ 档位可用 |
| 状态·警示 | 暖琥珀 `#FFB86B` | ⚠️ 域外降级提示 |
| 状态·危险 | 玫红 `#FF6B9D` | ❌ 失败/回滚 |
| 文·月白 | `#EAEAF2` 主文 / `#9A9AB8`（60% 月白）辅文 | 标签/正文 |
| 描边 | 月白 12% 透明度，1px | 卡片细描边 |

## 三、材质与形状

1. **卡片**：`UIVisualEffectView`（`UIBlurEffect.systemChromeMaterialDark`）+ 24pt 圆角 + 1px 月白 12% 描边（CAShapeLayer）。浮起阴影 `#000 40%`，y=12，blur=32。
2. **按钮**：44pt 高；主操作=极光渐变（16pt 圆角，按压 scale 0.97）；次操作=深紫底+月白描边玻璃感。
3. **降级路径**：`UIVisualEffectView` 不可用场景 → 纯色 `#1B1443` 85% 透明度。

## 四、动效三件（全 CA 原生，零依赖）

1. **星尘微粒**：CAEmitterLayer，birthRate 12/s，月白 60% 1.5pt 圆点，缓慢上升漂移；仅挂主背景层（卡片层不加——克制律）。
2. **极光流光**：CAGradientLayer locations 3s 循环动画（主按钮内）。
3. **涟漪反馈**：成功时 12% 月白圆环扩散淡出（1.2s）。

**无障碍**：`UIAccessibilityIsReduceMotionEnabled` → 全动效关停（静态深空底保底）；AOD/低电量环境粒子降频 50%。
**实现载体**：`TrollE-Installer/src/EUFairyStyle.h/.m`（B 线，§一~§四 落地）。
