## 一、结论速览（供 B23 修订）

1. **"不越狱可用"在机制上成立且已被 TrollStore 充分验证**——TrollStore 本体就是 *jailed（被囚禁态）permasigned 应用*，装好后永不依赖越狱；常驻靠 Persistence Helper，不靠任何越狱原语。
2. **免越狱安装需要一次性的漏洞链**（安装≠使用）。公开先例三线：kfd+dmaFail（设备端，TrollInstallerX）、CVE-2024-44252 备份注入（PC 端，TrollRestore）、MacDirtyCow（旧系统）。**Euphoria 树内已有 kfd 三 flavor + dmaFail（Dopamine 2.x 同源），免越狱安装链有现成地基。**
3. **EU 源出"安装器"有精确上游先例**：Havoc 源 `com.opa334.trollstorehelper`（TrollStore Helper deb）——越狱用户从源里装 helper、helper 装出 TrollStore 本体；本体此后不依赖越狱。用户 08:42 口径与该模式逐字吻合。
4. **硬边界（诚实口径）**：CoreTrust bug 于 16.7.x 正式版/17.0.1+ 被修复且无第三个 CT bug 公开 → **巨魔E 免越狱可用范围 ≤ iOS 17.0**（14.0b2–16.6.1 / 16.7 RC 20H18 / 17.0 四个 build）；**26.x 无 CT bug，免越狱不可达**，26.x 上巨魔E 只能走越狱态 trustcache 路线（B23 已有）。

## 二、不越狱可用的三块地基

### 地基 1：CoreTrust 多重签名验证缺陷（CVE-2023-41990 系）
- 机制：AMFI/CoreTrust 对**含多个签名者的二进制**不做正确校验 → TrollStore 以"假根证书"重签任意 IPA，任意 entitlements 经 ldid（`ldid -S`）预签后在安装时被保留（opa334 README 官方原文）。
- 产物：permasigned 常驻应用，无 7 天签名过期、无企业证书吊销问题。

### 地基 2：支持矩阵（硬边界）
| 维度 | 范围 |
|---|---|
| 支持 | iOS 14.0 beta2 – 16.6.1；16.7 **RC（20H18）**；17.0（21A326/327/329/331 全四个 build） |
| 永不支持 | 16.7.x 正式版（除 RC）、17.0.1+（除非发现第三个 CT bug，上游判断"不太可能"） |
| 设备 | A8–A17 / M1–M2（A8 仅 14.0–15.1 走 TrollInstallerX 直接法） |
- 与 Euphoria 核心范围（A12–A16 / 15.0–16.6.1）**完全重叠**——巨魔E 免越狱覆盖我们全部主力用户。
- **26.x 挑战线（R16）与免越狱巨魔互斥**：CT 已修复，只能越狱态使用。

### 地基 3：Persistence Helper（常驻机制，必做组件）
- CT bug 只能把应用注册为 **System 态**；FrontBoard 在每次启动 User 态应用前经 libmis 再校验 → **图标缓存重载后所有 CT 安装的应用退回 User 态、无法启动**。
- 解法：把 helper 注入一个系统应用（官方推荐 Tips 等），图标缓存重载后用 helper 把 TrollStore 及其装的应用**重新注册回 System 态**。
- 工程含义：**任何安装向量（含 EU 源安装器）都必须部署 Persistence Helper**，否则一次 respring/uicache 即失效。越狱态 iOS 14 时代 TrollHelper 例外（/Applications 常驻 System）。

## 三、安装器路线全景（EU 源安装器的参照系）

| 路线 | 载体 | 范围 | 机制 | 关键限制 |
|---|---|---|---|---|
| **TrollInstallerX**（alfiecg24，1.0.3） | 设备端 App（侧载后一键） | 直接法：14.0–16.6.1 arm64 / 14.0–16.5.1 arm64e；间接法：16.5.1–16.6.1 arm64e | **kfd 内核漏洞 + dmaFail PPL bypass**（直接法一次装本体+helper）；间接法=替换系统应用为 helper | A15/A16/M2@16.5.1 dmaFail 失效→走间接法；16.6+ 无 PPL bypass→间接法；15.7.2–15.8.2 与 16.2–16.6.1 需联网下载 kernelcache 做 patchfind |
| **TrollRestore**（JJTech0130） | PC 端（macOS 11+/Win10+iTunes，pymobiledevice3） | 15.2–16.7 RC + 17.0 全部 | **CVE-2024-44252（MobileBackup）sparserestore**：把 TrollHelper 二进制还原进系统应用容器 | PC 依赖；被替换的系统应用只能删除重装复原；<15.2 禁用 |
| TrollInstallerMDC | 设备端 | 15.0–16.1.2 | MacDirtyCow（CVE-2022-46689） | 旧系统才可用 |
| **TrollStore Helper（Havoc 源 deb）** ⭐ | **源 deb（越狱态）** | 任意越狱设备 | 越狱原语直装本体+helper | 需已越狱 |
- iDownloadBlog 佐证：TrollStore 可作为 .deb 安装；Reddit r/jailbreak 常见口径："if you're jailbroken already, just install trollstore helper"。

**→ 巨魔E 安装器（EU 源 deb）建议双模式**（与用户口径精确对齐）：
1. **越狱态模式**（B23 已有，trustcache 注入 + ldid 假签 + 幂等重放）：秒级安装本体+helper，无需漏洞链；
2. **免越狱模式**（TrollInstallerX 同构）：内嵌 kfd+dmaFail 链，未越狱用户侧载/打开安装器后一键获得巨魔E——**树内 exploits-module 的 kfd flavor 与 Dopamine 2.x dmaFail 均可直接复用**，这是相对上游 TrollInstallerX 的零边际成本优势。
- 装出本体后：卸载越狱/restore rootfs/重启，巨魔E 照常可用（CT 地基与越狱无关）。

## 四、工程要点清单（B23 修订输入）

1. **Persistence Helper 必做**：图标缓存重载后 System 态回退问题；helper 槽位选择 UI（系统应用列表）。
2. **dmaFail 设备差异表**（TrollInstallerX 实证）：16.6+ arm64e 无 PPL bypass → 只能间接法（先 helper 后本体）；A15/A16/M2@16.5.1 dmaFail 坏 → 间接法；**Euphoria 主力 A12–A14 用户全版本直接法畅通**。
3. **URL Scheme 劫持先例**：TrollStore 劫持系统 `apple-magnifier://` scheme（反越狱检测探测），支持 `apple-magnifier://install?url=` 浏览器直装与 `enable-jit?bundle-id=`（2.0.12+）——巨魔E 同款设计可复用（R8 隐藏口径加分项）。
4. **Entitlements 边界**：A12+ iOS15 起三个未签名代码相关 entitlement 被 ban，无 PPL bypass 不可得——巨魔E 文档须如实标注（与 CT 无关的独立限制）。
5. **更新流**：应用内自更新按钮 + TrollStore.tar 兜底（在 TrollStore 内打开即装）——巨魔E 可复用该自更新模式，EU 源同时托管更新包。
6. **版本状态**：TrollStore 2.0.15（alfiecg24，2026-03-30 发布）；AppleWiki 记 stable 2.1.1（2026-04-01）——上游活跃维护中，巨魔E fork 基线建议取 2.0.15+（若 2.1.1 确认存在则取最新）。
7. **免越狱范围的对外口径**：≤17.0（含 17.0 四 build + 16.7 RC）；17.0.1+/16.7.x 正式版/26.x = 仅越狱态可用。
