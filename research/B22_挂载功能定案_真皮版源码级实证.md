## 1. 语义定案（用户指定参照后，此前"挂载=A/C 组合"的猜测作废）

"挂载" = **系统目录 bind mount 到 /var/jb 镜像**：App 设置里"新增挂载"（输入系统只读路径，如 `/System/Library/CoreServices/VoiceOverTouch.app/Sounds`）→ 工具把该目录拷贝到 `/var/jb/mnt/<原路径>` 镜像 → `bindfs` 只读挂载覆盖原路径 → 系统读到镜像内容（改字体/音效/温控等系统资源的标准 rootless 手法，绕过 SSV 只读限制；**非越狱态重启后自动失效恢复原样**——真皮版教程原话确认）。

## 2. 全链路实现规格（真皮版源码，文件:行号）

### 2.1 设置 UI（DOSettingsController.m:795-895）
- **"新增挂载"**（`Input_Mmount_Title`）：UIAlertController 文本框收路径 → 校验存在且为目录（失败弹 `Error_Mount_Body`，提供"重新挂载"按钮重试）→ 写 `/var/jb/mnt/newFakePath.plist`（结构 `{"path": [路径数组]}`，去重追加）→ **立即执行** `fakeMount:unmount:NO shouldDeleteMntFiles:NO`（当场生效，不用重越狱）
- **"管理挂载"**（`Input_Unmount_Title`）：actionSheet 列出 plist 全部路径，每项三操作：
  - 仅删记录（`Button_Delete_Path_Only`，destructive）
  - 取消挂载（`Button_Delete`，destructive）= 卸载 + 删镜像文件 + 删记录
  - 查看（`Button_View`）= `filza://view<路径>` 跳转 Filza

### 2.2 底层挂载（BaseBin/jbctl/src/internal.m:95-138）
- `fakePath_is_mounted(path)`：`statfs()` 比对 `f_mntonname == path`
- `initMountPath(path)`：镜像初始化——`/var/jb/mnt/<path>` 不存在或为空时，系统目录 **copy→tmp→move 原子拷贝**到镜像位（跨卷，APFS CoW 不生效，占等量存储——liam.page 教程明确）
- `fakePath_mount(mount, path)`：
  - 挂载 = `mount_unsandboxed("bindfs", path, MNT_RDONLY, "/var/jb/mnt<path>")`（libjailbreak unsandboxed host 接口，**MNT_RDONLY 只读**）
  - 卸载 = `unmount_unsandboxed(path, MNT_FORCE)`
- 命令行入口：jbctl `:245` mount / `:262` unmount（热更新可用）

### 2.3 越狱时自动挂载（DOJailbreaker.m:877-891 `fake_mount()`）
越狱流程读 newFakePath.plist → 逐路径 `fakeMount` —— README 原话："APP内挂载系统目录（修改字体，温控类）；越狱时自动挂载上面功能添加的目录"。（注：源码里 `mountEnabled` 总开关被注释掉，即无开关、恒自动挂载）

### 2.4 本地化（zh-Hans 已备，直接沿用）
新增挂载/管理挂载/取消挂载/仅删除路径/应用绑定挂载。
