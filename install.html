第 1 步 · 安装防掉签描述文件 （必装）

先在 Safari 点下方按钮下载，然后去 设置 → 通用 → VPN与设备管理 → 已下载的描述文件 → 右上角安装。仅屏蔽苹果「证书吊销在线验证」域名，不影响正常上网。

① 下载描述文件
第 2 步 · 安装 Euphoria 本体

回到本页点按钮，弹窗确认后回桌面等图标出现（1-2 分钟）。

② 立即安装 Euphoria
第 3 步 · 信任企业证书

设置 → 通用 → VPN与设备管理 → China Telecom Corporation Limited → 信任。iOS 18+ 装完重启一次。

排障：装不上=先确认第 1 步描述文件已安装生效；图标灰着等一会；打不开=第 3 步没信任。本方案基于免费共享企业证书（苹果吊销后靠描述文件屏蔽验证），属社区标准免费玩法，掉签不影响已装 App 启动。移除描述文件：设置→通用→VPN与设备管理→移除已下载的描述文件。
