⚠️ 安全须知（必读，再决定）

本方案会安装「反撤销 DNS」描述文件：它把全设备 DNS 交给第三方（越南 khoindvn）网关，并全局关闭苹果对企业签 App 的吊销验证——等于关掉一扇安全门，恶意 App 也可能趁虚而入。

更干净、无此代价的替代：Safari 打开 usescarlet.com 用 Scarlet 平台签名（全程 2 分钟）。两条路你选。

STEP 1

① 安装反撤销 DNS 描述文件

点按钮 → 跳「描述文件已下载」→ 设置 → 通用 → VPN与设备管理 → 安装「Anti Revoke」。

若按钮无效（Safari 拦截）：长按本页任意处→全选本页地址改用手动法——电脑或另一设备无法替代，请在 iPhone 上用 Safari 打开本页。

STEP 2

② 重启 iPhone

必须重启：清除昨天安装失败留下的吊销缓存。不重启，死证链装上也会闪退。

STEP 3

③ 安装 Euphoria v1.0.7

重启完成后点按钮 → 弹出安装确认 → 桌面出现 Euphoria。

装完若仍「无法验证App」：说明本方案在你的 iOS 18.1.1 上失效（吊销验证关不掉），删掉描述文件（设置→VPN与设备管理→Anti Revoke→移除），改走 Scarlet 路线即可。

✅ 更稳的 Scarlet 路线（无安全代价）

Safari 开 usescarlet.com → Install 装猩红 → 信任证书 → 导入群里的 Euphoria 正名版 ipa → 签名安装。平台证书连续 3 天复核存活。
